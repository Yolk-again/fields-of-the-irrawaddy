FIELDS OF THE IRRAWADDY — PIXEL ASSET PACK (V4)

All art is true pixel art, transparent PNG, authored at 16px tiles and shown in-game at 2x
(Phaser `pixelArt: true`, nearest-neighbour). Everything is generated by code:

    python3 -m pip install pillow
    python3 tools/pixel_art/build.py      # rewrites public/assets/* and asset-manifest.json

Edit the generators in tools/pixel_art/ (palette ramps, shapes) and re-run to restyle.

Sheets: characters/*_sheet.png = 4 walk frames x 3 rows (down, up, side) of 16x26.
Animals: chicken/duck 16x16 (3 frames), water buffalo 44x30 (4 frames).
FX: fx/dust, splash, sparkle (4x 16x16), water_glint (4x 8x8), butterflies (2x 8x8).
Burmese touches: khamauk hat, longyi, thanaka, gaung baung, stilt houses, kyaung monastery,
golden zedi, toddy palms, bamboo, banana, lotus pond, water buffalo, rice paddy.

V3 additions: monk + kid sheets (4x5 frames: down, up, side, work, sit), village props (assets/village),
HUD icons (assets/ui/icon_*.png). Layout lives in src/game/data/villageLayout.ts.
