FIELDS OF THE IRRAWADDY — VERCEL-READY V7

VERCEL BUILD SETTINGS
- Framework preset: Vite
- Project root: the folder containing index.html, package.json, and vercel.json
- Install command: npm ci
- Build command: npm run build
- Output directory: dist
- Node.js: 22.x (package.json engines; local .nvmrc uses 22.16.0)

TITLE / SAVE SELECT
- Save selection is rendered before Phaser starts.
- Phaser.Game is created only after a slot action is selected.
- Three independent slots, legacy migration, overwrite confirmation, and delete confirmation are preserved.
- The save reader and loader now share the same supported version check (1 through 14).
- Failed loads no longer mark an existing game as ready for autosave.
- Saves are flushed on visibility changes and when the Phaser scene shuts down.

LOADING ANIMATION
- The wheat emoji continues spinning even when Windows requests reduced motion.
- The loading dots still respect reduced-motion settings.

FAVICON / SEARCH METADATA
