# Multiple Daily Village Requests

- The village request board now generates three independent requests per in-game day.
- Each request has its own item, quantity, progress, delivery action, reward, and completion state.
- Request types continue to unlock with the existing day progression: rice first, then tomatoes and green beans, then fish, then cooked meals.
- Early days generate different rice quantities so the board still offers three achievable tasks before more item types unlock.
- Desktop players can deliver requests with the matching 1, 2, or 3 key, or by clicking each row's Deliver button. Touch players can tap the Deliver buttons.
- All three requests are saved and restored. Existing saves containing the previous single-request format are upgraded by preserving their current request and generating the remaining daily requests.
- Request-board instructions and statuses are translated in English and Burmese.
