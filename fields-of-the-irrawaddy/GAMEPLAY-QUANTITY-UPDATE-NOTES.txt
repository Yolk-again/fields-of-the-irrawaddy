FIELDS OF THE IRRAWADDY — FARMING & QUANTITY UPDATE

FARMING TIMER
- Each plot stores the in-game minute when it was watered.
- It advances one growth stage only after 1,440 in-game minutes (24 in-game hours) from that watering.
- The village clock runs at 250 ms per in-game minute, so one full in-game day currently takes 6 real-world minutes.
- Sleeping, changing locations, autosaving, and reloading do not restart the watering timer. The timestamp is saved with each plot.
- Old save files remain supported. Old watered plots without a timestamp begin a fresh 24-hour in-game timer when that save is loaded; legacy planted plots get a fresh dry-care reference time.
- After the 24-hour growth cycle, crops need watering again. The existing wilt/death behaviour is retained, measured from the latest watering.
- Harvesting (including clearing a dead crop) returns the plot to untouched ground. Hoe it again before planting another seed.

SAVING
- The periodic autosave still runs every 10 seconds, but it no longer writes an AUTO-SAVED banner to the HUD. Manual save/load feedback remains available.
- Save format version is now 11; older supported versions still load.

QUANTITY CONTROLS
- Home storage rows now have −, +, MAX, STORE, and TAKE controls.
- Market sales use the same shared quantity rules and keep the MAX button.
- Market purchases now use the quantity selector too: rice-seed packs (5 seeds per pack, 10 coins per pack) and the unique fishing rod.
- Shared helper functions live in src/game/ui/QuantityMath.ts. New purchasing/selling systems should use these helpers so amounts clamp to available stock/funds and MAX always selects the largest valid quantity.
