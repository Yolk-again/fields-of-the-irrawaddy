HOW TO MAKE THE LIVE GAME LINK USE THIS VERSION

1. Extract this project into a clean folder.
2. Open that folder in VS Code. It must contain index.html, package.json, vite.config.ts, src/, and public/.
3. Run:
   npm install
   npm run build
4. Deploy the generated dist/ folder (not the old dist folder and not a different branch/folder).
5. Open the live URL in a private/incognito tab or hard-refresh it.
6. Use View Page Source and search for:
   mobile-startup-v5-2026-11-10
   If that text is missing, the live URL is still serving an older deployment or a different project root.

For GitHub Pages, make sure the deployment workflow publishes the new dist/ directory from this project's current branch. For Netlify/Vercel, make sure the build command is npm run build and the publish/output directory is dist.

The source code guarantees no Phaser.Game is created during initial page load. Phaser is created only after the player clicks a save-slot action. If a live URL still enters gameplay immediately and the build marker is absent, that URL has not received this build.
