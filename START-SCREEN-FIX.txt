FIELDS OF THE IRRAWADDY — STARTUP + MOBILE HEADER V5

TITLE / SAVE SELECT
- The title/save screen is present in index.html and explicitly forced visible in the initial HTML head styles.
- The main game app is hidden until FarmScene has finished initializing a selected save.
- main.ts does not construct Phaser.Game on page load. The only Phaser.Game constructor call is inside launchGame(), which is invoked by a save-slot action.
- FarmScene reveals the game only after its world, systems, and touch controls are initialized.
- Three independent save slots, legacy migration, and overwrite/delete confirmation are preserved.

MOBILE HEADER
- The six existing buttons (inventory, profile, language, help, audio, fullscreen) are now outside #game-container.
- The header uses position: fixed, so Phaser canvas clipping and z-index cannot hide it.
- Buttons are shown when the touch/mobile game is running; they are no longer hidden by the portrait CSS rule.
- Each button dispatches to the existing action handler in FarmScene.
- Existing icon files are reused; no new gameplay icons or desktop UI changes were added.

DEPLOYMENT PATHS
- Vite is configured with base: "./" for root and project-subfolder hosting.
- The HTML entry script and mobile icon images use relative paths.
- Phaser public asset paths use import.meta.env.BASE_URL so GitHub Pages-style project URLs can load them.
- index.html contains meta name="foi-build" content="mobile-startup-v5-2026-11-10" as a deployment-version marker.

IMPORTANT DEPLOYMENT NOTE
The currently hosted URL must be rebuilt/redeployed from this project. Editing or extracting a ZIP does not update an already hosted link.
Run npm install, npm run build, then deploy the contents of dist/ using the hosting provider's normal deployment process. After deploying, hard-refresh the link or test it in a private/incognito tab. View page source and search for "mobile-startup-v5-2026-11-10" to confirm that the URL is serving this version.
