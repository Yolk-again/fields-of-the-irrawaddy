# Mobile Title, Market Price, and Chest Layout Update

- Changed the mobile landscape title page into a vertically scrollable welcome screen. The title and countryside artwork appear first; save slots and the install action are below.
- Added an English and Burmese swipe-up cue that remains visible while the save slots and install action are below the viewport, then hides once the install action is reached.
- Changed market menu badges to show seed-pack costs, bait costs, crop sell prices, fish sell prices, and meal sell prices instead of backpack quantities.
- Kept the owned quantity in the selected-item detail/quantity panel beside the item description, with separate wording for seed packs and single-unit bait.
- Reworked chest column headings into separate Backpack, Chest, and Amount labels. Chest item names are constrained to one line and row action buttons no longer overlap adjacent rows.
- Updated the service-worker shell cache revision and deployment marker for this release.
